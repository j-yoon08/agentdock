# AgentDock MVP Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Build a self-hosted read-only AI Agent Control Plane MVP that shows agents, automation events, failures, approvals, and connector health.

**Architecture:** Use a dependency-free Node.js HTTP server with a static frontend and a JSON-backed read model. The first version is explicitly read-only: no action execution, no external writes, and no credentials.

**Tech Stack:** Node.js 22 built-in `http`, static HTML/CSS/JS, Node `node:test`, JSON sample state.

---

## Product boundary

- Name: AgentDock.
- Category: AI Agent Control Plane / personal automation operations console.
- MVP mode: read-only.
- Must show: Today cockpit, Agent Registry, Pending Approval, Failure Triage, Connectors, Activity Timeline.
- Must block: all POST `/api/*` requests.
- Must avoid: external writes, real OAuth, production secrets, financial actions, publishing actions.

## Tasks

### Task 1: Create local project scaffold

**Files:**
- Create `package.json`
- Create `.gitignore`
- Create `README.md`
- Create `docs/product-brief.md`

**Verification:**
- `npm run check` should be available.
- No external dependencies should be required.

### Task 2: Create sample read model

**Files:**
- Create `data/sample-state.json`

**Acceptance:**
- Include 5 agents, 3 approvals, 4 events, 2 failures, and 4 connectors.
- Include at least one critical/blocked example to prove fail-closed UX.

### Task 3: Implement read model helpers

**Files:**
- Create `src/control-plane.js`

**Acceptance:**
- `loadState()` loads JSON.
- `normalizeState()` rejects unsafe workspace modes.
- `publicState()` redacts token-like values.
- `summarizeState()` computes KPIs, health, today queue, and risk counts.

### Task 4: Implement HTTP server

**Files:**
- Create `src/server.js`

**Acceptance:**
- `GET /api/health` returns `status: ok`.
- `GET /api/summary` returns AgentDock summary.
- `GET /api/state` returns public redacted state.
- `POST /api/*` returns 405 with `read_only: true`.
- Static files are served from `public/`.

### Task 5: Build compact dashboard UI

**Files:**
- Create `public/index.html`
- Create `public/styles.css`
- Create `public/app.js`

**Acceptance:**
- Above the fold shows product, mode, health, active agents, approvals, failures, and cost.
- Main surfaces show Today cockpit, agent table, approvals, failures, connectors, timeline.
- CSS is responsive and avoids decorative edge bars/gradients.

### Task 6: Add contract tests

**Files:**
- Create `test/control-plane.test.js`
- Create `test/server.test.js`
- Create `test/ui-contract.test.js`

**Verification:**
- Run `npm run check`.
- Run `npm test`.

### Task 7: Smoke test locally

**Commands:**

```bash
PORT=4177 npm start
curl -sS http://127.0.0.1:4177/api/health
curl -sS http://127.0.0.1:4177/api/summary
```

**Acceptance:**
- Health returns HTTP 200.
- Summary returns `product: AgentDock` and `mode: read_only_mvp`.
- Homepage contains `AgentDock` and core panels.
